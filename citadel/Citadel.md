# Citadel




- 3D Shoot 'em up / Bullet hell
- 3 Power ups - Magnet, Laser, Shield
- 3 Enemy types - Normal, Tank, ???
- 3 Levels
- Star system for unlocking levels
- You can upgrade your ship using coins collected from enemies - HP, Damage, Shooting speed, Power up time

Player needs to clear the level and get stars to unlock the next one

Every level can get you 3 stars for killing all enemies
